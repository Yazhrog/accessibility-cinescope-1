# CinéScope — Projet Accessibilité Web (A11y)

Projet de mise en conformité et d'optimisation de l'accessibilité numérique selon les standards **WCAG 2.1 AA/AAA** et **RGAA**.

## 👥 Binôme
- **Thomas Polverelli**
- **Clément Pasteau**

---

## 🚀 Installation et Lancement

1. Installer les dépendances :
   ```bash
   npm i
   ```

2. Lancer le serveur de développement :
   ```bash
   npm run dev
   ```

3. Compiler pour la production :
   ```bash
   npm run build
   ```
